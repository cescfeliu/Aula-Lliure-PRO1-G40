# PRO1 — Aula Lliure (G40) 💻

Material de suport, apunts resumits i exercicis resolts per a les sessions d'Aula Lliure de **Programació 1 (C++)** a la FIB.

---

## 🎯 Què hi trobaràs aquí?

- **Apunts sintètics:** Resums de cada bloc temàtic centrant el focus en els conceptes clau que solen portar més confusions a classe.
- **Exercicis resolts pas a pas:** Problemes típics d'examen i del [Jutge.org](https://jutge.org/) amb explicació de l'estratègia de resolució abans del codi.

---

## 📍 Sessions Presencials

| Aula | Dia de classe | Horari |
| :--- | :--- | :--- |
| B5S202 | Divendres | 12:00h - 14:00h |

Les sessions són obertes: pots venir a fer exercicis del [Jutge.org](https://jutge.org/), repassar teoria o portar codi que et doni problemes (*Wrong Answer*, bucles infinits, *Segmentation Fault*, etc.) i ho mirem a la pissarra o a la pantalla.

---

### 🕒 Com funcionen les sessions presencials?

- **Format obert:** Pots venir amb el teu propi portàtil o utilitzar directament els ordinadors de l'aula de laboratori.
- **Treball individual o en grup:** Pots treballar de forma autònoma fent exercicis del Jutge i cridar el professor de suport quan detectis un bloqueig, un *Execution Error* o dubtis sobre l'eficiència del teu enfocament.
- **Revisió de controls de laboratori (CL):** Abans de cada control pràctic, farem simulacres de problemes amb límit de temps per agafar soltesa amb les eines i la consola.
- **Preparació de l'Examen Parcial i Final:** Resolució guiada d'exàmens d'anys anteriors i tècniques d'esquematització d'algorismes a paper/ordinador.
