# PRO1 — Aula Lliure (G40) 💻

Material de suport, apunts resumits i exercicis resolts per a les sessions d'Aula Lliure de **Programació 1 (C++)** a la FIB.

---

## 🎯 Què hi trobaràs aquí?

- **Apunts sintètics:** Resums de cada bloc temàtic centrant el focus en els conceptes clau que solen portar més confusions a classe.
- **Exercicis resolts:** Problemes típics d'examen i del [Jutge.org](https://jutge.org/) treballats a classe.

---

## 📚 Temari i Apunts

| Bloc | Contingut |
| :--- | :--- |
| [01-Introduccio](01-Introduccio/README.md) | Variables, condicionals, tipus de dades, conversions i visibilitat |
| [02-Bucles-i-Sequencies](02-Bucles-i-Sequencies/README.md) | Bucles `while`/`for`, recorregut, cerca i finestres |
| [03-Funcions](03-Funcions/README.md) | Funcions, accions (`void`) i pas per valor vs. referència |
| [04-Recursivitat](04-Recursivitat/README.md) | Cas base, cas recursiu, pila de crides i exercicis |
| [05-Vectors](05-Vectors/README.md) | Vectors, `string`, cerca lineal/binària, cost ($O$) i `sort()` |
| [06-Matrius](06-Matrius/README.md) | `typedef`, recorreguts, disseny *Top-Down* i producte de matrius |
| [07-Tuples](07-Tuples/README.md) | `struct`, composició, ordenació de tuples i `push_back()` / `pop_back()` |
| [08-Algoritmes-fonamentals](08-Algoritmes-fonamentals/README.md) | Inserció, selecció, fusió de vectors i *Mergesort* ((n log n)) |
